# Editing Guide

Use `site.json` as the main control panel for the website.

- Replace `profile.name`, `headline`, `intro`, `location`, and `email`.
- Add resume entries in `experience`.
- Add portfolio cards in `projects`.
- Add tutoring subjects in `tutoring.subjects`.
- Put future images in `public/assets/` and reference them from components or content.

The visual theme lives in `src/styles/global.css`.
